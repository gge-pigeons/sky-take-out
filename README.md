# 苍穹外卖

苍穹外卖是一个基于 Java 后端和微信小程序客户端的外卖点餐项目，包含管理端和用户端功能。

本项目学习时间：2026年10月24日—2026年11月2日。

## 项目功能

### 管理端

- 员工登录与员工管理
- 菜品分类管理
- 菜品管理
- 套餐管理
- 菜品口味管理
- 员工账号启用与禁用
- 订单管理
- 接单、拒单、配送、完成订单
- 营业数据统计
- 用户数据统计
- 订单数据统计
- 销量排名 Top10
- WebSocket 来单提醒
- 语音播报订单通知

### 用户端

- 微信登录
- 店铺状态查询
- 菜品和套餐浏览
- 菜品分类查询
- 购物车管理
- 地址簿管理
- 提交订单
- 微信支付
- 订单历史查询
- 订单详情查看
- 取消订单
- 再来一单

## 技术栈

### 后端

- Java
- Spring Boot
- Spring MVC
- MyBatis
- MySQL
- Redis
- PageHelper
- JWT
- WebSocket
- 阿里云 OSS
- 微信支付
- 百度地图 API

### 前端

- Vue
- 微信小程序
- Axios
- Nginx
